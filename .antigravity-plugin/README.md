# Lightbringer

Work with [Lightbringer's patent service](https://lightbringer.com) from Antigravity. Lightbringer has qualified patent attorneys on its team providing advice, strategy assessment, novelty searches, FTO, drafting, filing and prosecution through professional engagements.

The plugin connects to your private Lightbringer organisation through the Lightbringer MCP server (`https://mcp.lightbringer.com/mcp`). On first use, sign in to Lightbringer in the browser and choose the organisation to connect. Existing record permissions still apply. Never paste passwords or access tokens into chat.

## Install

Extract `lightbringer-antigravity-<version>.zip`, then install the extracted
directory with `agy plugin install <directory>`. Use this generated native
package; the repository root also contains other hosts' distribution files.
See [distribution status and validation](https://github.com/lightbringer-patents/agent-plugin/blob/main/DISTRIBUTION.md#google-antigravity).

## Skills

- **setup:** get oriented from your current IP situation and develop a practical first plan, saved as a draft Strategy when requested.
- **innovation-capture:** identify, register and enrich innovations from a conversation, inventor interview or authorised technical sources.
- **ip-strategy:** build, review and update an IP strategy from business objectives and accessible evidence.
- **patent-portfolio:** review saved patent portfolios and families, find public publications and carry out authorised imports or family updates.
- **novelty-exploration:** explore related and competitor patents for a technical idea. This is preliminary exploration, not a novelty or freedom-to-operate assessment.
- **patent-preparation:** request Lightbringer's preparation of a selected innovation for patent filing.
- **patent-review:** read review instructions and documents, draft feedback, and carry out approved comments, country choices or review responses.
- **journeys:** follow a listed journey only when the connected service advertises its tools; otherwise use the relevant workflow.
- **company-context:** establish and maintain the shared company background used in IP work.
- **trade-secrets:** explain trade secrets and list the register entries you can open, without entry content.
- **lightbringer-navigation:** explain the patent process and choose a relevant next step.

Registering an innovation does not request patent preparation. Payment, filing and attorney-led services go through the Lightbringer team.
